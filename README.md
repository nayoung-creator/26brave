# 1·2·3 런 — 학교 운동장 마일리지

유치원~6학년 전교생과 희망 교직원이 학교 운동장을 한 바퀴 돌 때마다 마일리지를 쌓는 학교 자체 런 프로젝트 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

학생과 교직원이 쓰는 주소는 [https://26brave-run.surge.sh](https://26brave-run.surge.sh) 입니다. 이 주소는 이 컴퓨터를 꺼도 그대로 열립니다.

## 계정

- 참가자는 회원가입으로 아이디와 비밀번호를 만듭니다.
- 참가자는 비밀번호를 변경할 수 있습니다.
- 관리자는 참가자 마일리지·비밀번호 확인, 초기화, 다른 계정 삭제가 가능합니다.
- 관리자 비밀번호는 로그인 화면에 표시하지 않습니다.

## 주요 기능

- 운동장 1바퀴 = 1 마일리지 기록
- 오늘의 기록 / 이번 달의 기록
- 참가자 현황(운동장 트랙 위 동물)
- 가입 시 동물 10종 중 선택 (강아지, 고양이, 토끼, 햄스터, 고슴도치, 도마뱀, 카피바라, 판다, 여우, 펭귄)
- 누적 50마일리지마다 3단계 진화
- 마일리지 상점: 옷 10종, 먹이 10종, 간식 9종
- 성장 배지 / 내 정보
- 관리자 계정 관리

여러 기기(휴대폰, 컴퓨터)가 같은 주소로 접속하면 계정과 마일리지, 동물 기록을 함께 사용합니다. 화면은 정적 페이지로 배포되고, 기록은 공통 데이터베이스에 바로 저장됩니다. 한 기기에서 저장한 바퀴 수는 다른 기기에 몇 초 안에 반영됩니다.

교실에서 보여줄 QR은 로그인 화면과 `/join` 페이지에 있습니다. 배포에 쓰는 데이터베이스 주소는 저장소에 올리지 않습니다.
