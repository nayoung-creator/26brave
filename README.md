# 1·2·3 런 — 학교 운동장 마일리지

유치원~6학년 전교생과 희망 교직원이 학교 운동장을 한 바퀴 돌 때마다 마일리지를 쌓는 학교 자체 런 프로젝트 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

## 계정

| 역할 | 아이디 | 비밀번호 |
|------|--------|----------|
| 관리자(기본) | `admin` | `admin123` |
| 참가자 | 회원가입으로 생성 | 직접 설정 |

- 참가자는 비밀번호를 변경할 수 있습니다.
- 관리자는 참가자 마일리지·비밀번호 확인 및 초기화가 가능합니다.

## 주요 기능

- 운동장 1바퀴 = 1 마일리지 기록
- 오늘의 기록 / 이번 달의 기록
- 참가자 현황(운동장 트랙 위 동물)
- 가입 시 동물 10종 중 선택 (강아지, 고양이, 토끼, 햄스터, 고슴도치, 도마뱀, 카피바라, 판다, 여우, 펭귄)
- 누적 50마일리지마다 3단계 진화
- 마일리지 상점: 옷 10종, 먹이 10종, 간식 9종
- 성장 배지 / 내 정보
- 관리자 계정 관리

데이터는 `data/store.json` 에 저장됩니다.
