# 용기반 독서기록장

2학년 용기반 친구 5명이 휴대폰으로 독후감을 남기고, 자기 책장에 책을 꽂아 두는 웹앱입니다.

학생은 노지호, 안이정, 윤설, 이서하, 이은우입니다. 처음 들어올 때 숫자 4자리 비밀번호를 만들고, 다음부터는 그 번호를 눌러야 책장이 열립니다. 선생님은 다섯 명의 마지막 접속 시각, 비밀번호, 비밀번호 초기화, 적어 둔 독후감을 모두 볼 수 있습니다.

책장은 처음에 비어 있습니다. 독후감을 저장하면 왼쪽부터 책이 꽂히고, 한 책장에 50권이 차면 다른 모양의 새 책장이 아래에 이어집니다. 다 채운 책장은 위에 남아 있어서 위로 밀어 다시 볼 수 있습니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 같은 와이파이에 있는 휴대폰은 컴퓨터 주소의 3000번 포트로 들어옵니다.

화면만 고쳐 가며 볼 때는, 서버를 `node server/index.js` 로 켜 둔 뒤 다른 터미널에서 `npm run dev` 를 실행하고 `http://localhost:5173` 을 엽니다.

처음 선생님 비밀번호는 `yonggi1234` 입니다. 들어간 뒤 바꿔 주세요. 학생 비밀번호는 선생님 화면에 그대로 보입니다. 반에서 함께 쓰는 짧은 번호라서, 기록 파일 `data/library.json` 은 교실 컴퓨터에만 두세요.
